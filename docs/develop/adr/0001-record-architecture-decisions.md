# 1. 設計判断を ADR に記録する

Date: 2026-10-09

## Status

Accepted

## Context

この project の設計判断を記録する必要がある。

## Decision

Michael Nygard の記事 [Documenting Architecture Decisions](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions) に従い、Architecture Decision Records（ADR）を使う。

## Consequences

詳しくは上記の記事を参照する。軽量な Rust 製 ADR tool は Josh Rotenberg の [adrs](https://github.com/joshrotenberg/adrs)、元の shell 実装は Nat Pryce の [adr-tools](https://github.com/npryce/adr-tools) を参照する。
