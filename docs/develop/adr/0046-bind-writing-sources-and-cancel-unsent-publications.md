# ADR-0046: 文章指針の適合性を検証し未送信の公開予定を取り消す

## Context

公開文章の最終検査だけでは、文章生成に使用した指針の読者や公開範囲を確認できない。機械的な文章検査には意味と事実の判断に限界がある。また、送信前に不要となった承認済み文章は、公開せずに失効させる必要がある。

## Decision

プロジェクト設定と指針のメタデータを文章生成前に照合し、選択した指針を正確な文章に結び付ける。公開OSSには専用の指針を使い、重要な文章は作成とは別のレビューで読者への適合性と事実を確認する。指針と設定のダイジェストにより、差替え時の再確認を必要とする。

プロジェクトの本番設定は明示し、匿名の試験設定からの自動継承を認めない。既存の非公開文章の検査は読取り専用とし、結果を公開リポジトリへ複製しない。機械的な不適合が見つからないことと、意味や参照時点の確認を区別する。

未送信の公開予定は、識別子、状態、元の承認、内容のハッシュ、取消理由、取消の承認を指定して取り消す。取消は追記専用の履歴とし、元の本文を変更しない。同じ取消の再実行は冪等とする。送信を開始した予定は取り消さず、正規の照合を必要とする。

正式配布は正本の clean なソースから行う。未保存の変更、所有者が不明な作業場所、孤立した作業場所、未整理の一時作業場所や生成物がある場合は拒否する。検出と削除を分離し、証拠と成果を保護する。

## Alternatives considered

最終出力の検査だけを行う方式は指針の不一致を防げない。機械的な検査から意味の承認を自動生成する方式は採用しない。未送信の予定を送信済みに変更する方式や保存データの直接編集は、実際の送信結果と監査履歴を壊すため採用しない。

## Consequences

新規の公開予定には指針のメタデータが必要になる。重要な文章の独立確認は本文と設定に結び付く。不要な未送信の予定を公開せずに解消できる。安全に整理できない作業場所がある場合は、ソースと証拠を保持したまま配布を停止する。

## Security and operational impact

これらは協調的な検査であり、指針メタデータやレビュー記録の暗号学的な認証、OS による保存先の隔離を提供しない。設定と証跡は信頼する経路で管理する。検査の成功から、未確認の事実や意味の完全な正しさを主張しない。

## Compatibility

既存の正式配布ファイルと tag は変更しない。取消済みの状態を解釈できない旧版への切替は、同じ保存先での操作再開を意味しない。v0.7.8 の戻し先は `linux-amd64` のみに存在する。一般化した利用手順は[文章指針](../writing-guidance.md)と[正式配布](../binary-release.md)に定める。

## Status

採用。実装と検証を修正版で準備し、独立レビューと正式配布の前提を満たすまで公開完了とは扱わない。
