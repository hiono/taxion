# ADR-100: 製品目的 — 人間の曖昧な思考を継続可能な協調作業へ昇華する

Date: 2026-11-20

## Status

Accepted

## Context

人間の依頼は、断片的なアイデア、希望、疑問、制約が混在した状態から始まります。一度の指示へ圧縮してAgentへ渡すだけでは、目的の変化や実装とのずれを継続的に扱えません。

## Decision

**Taxionは、人間の曖昧な思考を対話で整理し、複数のAgent / Roleによる協調とガードレールを通じて、意図したJobの完遂を支援します。**

- 質問、言い換え、整理、要約を通じて、目的・制約・受入条件を明確にします。
- 計画をJobとして保持し、新しい情報や成果に応じて更新します。
- 複数のAgent / Roleが調査、計画、実装、レビュー、修正を協調して進めます。
- Jobに目的、判断、問いと回答、実行状態、成果、証拠を関連付け、中断後も同じJobを再開できるようにします。
- 人間が判断・承認・介入する境界を維持します。
- ControllerはJobの同一性、承認、対象・資源境界、禁止副作用、認証・認可、データ整合性を強制します。

製品の価値は、利用者が意図を整理し、Agentと協調し、成果を確認・修正してJobを完遂できるかで評価します。Taxion自身の再構築も、この製品目的を検証する実利用シナリオとします。

## Consequences

Job、Role、協調、権限、永続化、成果・証拠の具体的な契約を下位ADRで定義します。内部構造や物理スキーマは本ADRで固定しません。

## Relationship to other ADRs

ADR-101は再構築原則、ADR-201はJobAggregate、ADR-300は内部協調、ADR-500は権限、ADR-800は製品受入れ、ADR-811はAgent Harness能力を定義します。
