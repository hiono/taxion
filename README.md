# Taxion

Taxionは、人間の曖昧な思考を対話によって整理し、実行可能な計画へ昇華し、複数のAgent / Roleの協調とガードレールによって、人間が意図した成果物とJobの完遂を支援するソフトウェアです。

Taxionは最初から完全な要求仕様や実装手順を利用者へ要求しません。断片的な考え、希望、疑問、違和感、未整理の制約を対話の出発点として扱います。目的・制約・受入条件を明確にし、計画、実行、質問、回答、レビュー、修正、中断、再開を同じJobの文脈へ結び付けます。

## 製品が実現すること

- 曖昧な依頼から目的、制約、受入条件を整理する。
- 新しい情報や成果に応じて計画を見直す。
- 複数のAgent / Roleが調査、計画、実装、レビュー、修正を協調する。
- 情報不足を質問、回答、明示した仮定、部分作業によって解消する。
- 人間が判断・承認・介入する境界を保持する。
- Jobの目的、判断、実行状態、成果、証拠を永続化し、同じJobを安全に再開する。
- 実行状態や成果の出所が不明な場合に、成功を推測せず安全に停止・照合する。

## 設計の基本原則

1. 製品目的と利用者価値を最上位の評価基準とする。
2. 旧設計の制約を温存せず、新しいドメイン不変条件から再構築する。
3. Jobの同一性、承認、対象・資源境界、禁止副作用、認証・認可、データ整合性を強制する。
4. 会話、提案、Roleの判断だけで実行権限を拡張しない。
5. ドメイン不変条件は生成・変更・保存・復元・外部入力の全経路で強制する。
6. Taxion内部6 Actor通信はJobMessage、外部Agent相互運用はA2Aとし、両者を混同しない。
7. 合成テスト、SDK互換性、実Provider実行、実Job完遂の証拠を混同しない。
